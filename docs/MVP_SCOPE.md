# MVP Scope

## In Scope (Phase 1 — Launch)
- Auth (Clerk) with roles Couple / Vendor / Admin
- Wedding profile creation + dashboard widgets
- Events CRUD + Smart Punjabi Event Templates (static template library for the 8 core ceremonies)
- Budget items per event + wedding-wide budget summary (auto-calculated)
- Guest database + per-event invite assignment + RSVP statuses
- Task list (manual, no auto-templates yet)
- Vendor directory: search/filter/sort, vendor profile pages, categories
- Vendor self-serve onboarding + Free/Silver/Gold/Platinum subscriptions via Stripe
- Vendor dashboard: profile views, website/phone/email clicks, subscription management
- Inspiration gallery (admin-curated, 8 categories)
- Basic wedding website builder (story, gallery, countdown, RSVP form, theme picker — no custom domain yet)
- Admin panel: vendor verification, review moderation, category/gallery/blog CMS
- SEO landing pages for category × city combinations (static-generated, top 50 cities × categories)

## Explicitly Deferred to Phase 2
- AI Wedding Assistant (all 4 AI features)
- Drag-and-drop master timeline (Phase 1 ships list-based event ordering only)
- Custom domain support for wedding websites
- Multi-language (Punjabi script) UI
- Native mobile apps
- Advanced vendor analytics (funnel, heatmaps)
- Gift registry integrations with third-party retailers
