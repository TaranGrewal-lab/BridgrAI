# Phase 2+ Roadmap

## Phase 2 (Months 4–6 post-launch)
- AI Wedding Assistant suite (checklist, budget, guest, vendor recommenders)
- Drag-and-drop master timeline
- Custom domain support for wedding websites
- Gift registry integrations (Amazon, John Lewis, regional equivalents)
- Vendor analytics v2: search impression funnel, competitor benchmarking (anonymized)
- Referral program for couples and vendors

## Phase 3 (Months 7–12)
- Punjabi script localization + multi-language support
- Native iOS/Android apps (React Native, sharing API layer)
- Marketplace-adjacent "Verified Vendor Network" badge program (still no booking/payments)
- Expansion: additional South Asian wedding traditions (Sikh, Hindu, Muslim Punjabi variants) as configurable templates
- Wedding planner agency accounts (multi-wedding management dashboard)

## Phase 4 (Year 2)
- White-label platform for regional wedding planning agencies
- Advanced fraud detection ML model for fake reviews/vendors
- API partner program (read-only vendor directory API for wedding blogs/media)
